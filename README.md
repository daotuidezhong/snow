# ❄ Snow

Windows 桌面下雪小程序。雪花从屏幕上方飘落，在所有窗口上方显示，但不挡鼠标，可以照常点击、打字。

用 Rust 编写，通过 DirectComposition + Direct2D 在显卡上绘制，exe 只有几百 KB，不用安装。

## 功能（v0.2.4）

**雪花**
- 程序生成的贴图：六角冰晶、蓬松雪团、柔和雪点，近处的冰晶会自转、翻滚
- 景深效果：远处的雪花小而模糊
- 真实的空气流动：雪花有惯性，随乱流（curl noise）打旋，阵风会一阵一阵地扫过屏幕

**积雪**
- 雪落在窗口顶部和任务栏上，先在附近铺开成薄薄一层，再慢慢整体叠高，表面柔和起伏，有颗粒感和闪光
- 积雪厚度有上限，可在菜单里选：不积雪 / 薄 / 中 / 厚；也可以一键清除积雪
- 窗口像屋顶一样会挡雪：被上方窗口挡住的地方不会积雪
- 堆满后，雪会从两端的圆角处一点点滑落
- 用鼠标快速划过雪堆，雪会被彻底扫干净、扫飞出去，落到下面没被挡住的地方继续堆积
- 快速拖动窗口时，窗口上的雪会顺着拖动方向甩出去；关闭窗口时雪会掉下来
- 窗口被别的窗口挡住、最小化或最大化时，积雪会保留，窗口回来时雪还在
- 大风时，积雪表面的雪粉会被吹走

**设置**
- 降雪量：小雪 / 中雪 / 大雪 / 暴风雪
- 风：无风 / 微风 / 大风，可选向左或向右吹
- 雪花大小：小 / 中 / 大
- `Ctrl+Alt+S` 暂停 / 继续，开机自动启动，设置自动保存在 `%APPDATA%\Snow\config.txt`

所有操作都在屏幕右下角托盘的 ❄ 图标里（右键或左键单击）。如果看不到图标，点任务栏上的 **^**。

## 编译

需要 Rust。在 Windows 上：

```bash
cargo build --release --target x86_64-pc-windows-msvc
```

在 Linux 上交叉编译（需要 `mingw-w64`）：

```bash
rustup target add x86_64-pc-windows-gnu
cargo build --release
```

生成的程序在 `target/x86_64-pc-windows-gnu/release/snow.exe`。

模拟部分的单元测试可以在任何系统上运行：

```bash
cargo test --target x86_64-unknown-linux-gnu
```
